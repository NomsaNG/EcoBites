# 🥗 EcoBites

**EcoBites** is a sustainable food delivery platform promoting eco-friendly, locally-sourced meals.

This project was developed during my time at the Le Wagon coding bootcamp, with a focus on full-stack web development and team work.

---

## Overview

EcoBites is a web application designed to connect health-conscious consumers with sustainable meal options. The platform emphasizes:

- 🌱 Locally-sourced, organic ingredients  
- 📦 Eco-friendly packaging and delivery methods  
- 🧑‍🍳 User-friendly interface for meal selection and subscription management  

---

## Features

- 👤 User authentication and profile management  
- 🍽️ Meal browsing with descriptions and nutritional information  
- 🧾 Subscription plans with customizable options  
- 📦 Order tracking and order history  
- 🔧 Admin dashboard for managing meals, orders, and users  

---

## Tech Stack

- **Frontend:** HTML, CSS, JavaScript  
- **Backend:** Ruby on Rails  
- **Database:** PostgreSQL  
- **Deployment:** Heroku  
- **Version Control:** Git & GitHub  

---

## ⚙️ Installation & Setup

1. **Clone the repository:**
   ```bash
   git clone https://github.com/NomsaNG/EcoBites.git
   ```

2. **Navigate to the project directory:
   ```bash
   cd EcoBites
   ```
3. **Install dependencies:
   ```bash
   bundle install
   yarn install
   ```
4. **Set up the database:
   ```bash
   rails db:create
   rails db:migrate
   rails db:seed
   ```
5. **Start the server:
   ```bash
   rails server
   ```
6. **Visit the application:
   ```bash
   http://localhost:3000
   ```
